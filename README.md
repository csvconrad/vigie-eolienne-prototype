# Vigie Éolienne — prototype

Prototype cliquable d'une plateforme citoyenne d'information et de mobilisation sur les projets éoliens au Québec.

Toutes les données (projets, documents, membres, groupes) sont fictives. Rien n'est enregistré.

Voir le prototype : https://csvconrad.github.io/vigie-eolienne-prototype/
